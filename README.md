## 使い方

1. ページにアクセスする
2. 画像をドラッグ＆ドロップ、またはクリックして PNG / JPG / WebP を選択する
3. **処理する** ボタンを押す
4. After 画像を確認し、**画像を保存** でダウンロードする
5. X に投稿する

### X 投稿時の目安

- 単一画像は **2:1〜3:4** の比率だとフル表示されやすい
- 一辺が **2048 px 以上**だとうまくいきやすい
- **4096 px を超える**と X 側で圧縮処理が入り、色が見えてしまう場合がある
