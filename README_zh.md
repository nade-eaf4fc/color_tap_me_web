## 使用方法

1. 访问该页面
2. 拖放图像，或点击选择 PNG / JPG / WebP 文件
3. 按下 **处理** 按钮
4. 查看处理后的图像，点击 **保存图像** 下载
5. 在 X 上发布

### X 发布提示

- 单个图像最佳宽高比为 **2:1 至 3:4**
- 长边 **2048 像素或更大**效果更好
- 超过 **4096 像素**可能会被 X 压缩处理，导致颜色显示
