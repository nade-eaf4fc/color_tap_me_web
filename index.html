Input
ここに画像をドラッグ＆ドロップ またはクリックして PNG / JPG / WebP を選択
まだ画像は読み込まれていません。
Action
画像を読み込むと処理できます。
X 向けの目安
  • 単一画像は 2:1 から 3:4 の範囲だとフル表示されやすいです。
  • 運用上の目安は、一辺が 2048 px 以上だとうまくいきやすいです。
  • 4096 px 以下にしないと、X 側での圧縮処理が入り、色が見えてしまう場合があります。
